Sid Nuke Tools

Eight compositing utilities for Nuke, split into two families: colour matching (Neutralize, Match Black, Match White, Match Colour) and edge work (Edge Extend Blur, Alpha Edge, Light Wrap) and lens work (Lens Flare). Written as plain Python nodes — each one solves for its correction live off the Source/Target pixels you give it, rather than asking you to eyeball sliders.

Overview

Independent files, one shared install step. Nothing here replaces Nuke's native Grade/Roto — these are solvers: give a node a Source and a Target (and optionally a Mask) and it works out the correction itself.

sid_match_tools.py

Neutralize, Match Black, Match White, Match Colour — four ways to pull a Source plate's tonal range onto a Target's.

sid_alpha_edge.py

Alpha Edge — grow, shrink (in 0.1 px steps), smooth and blur a rough matte edge.

sid_edge_extend.py

Edge Extend Blur — cleans the dark or bright rim on the RGB edge of a keyed element, with an optional Sample area and a final colour-only edge blur.

sid_light_wrap.py

Light Wrap — a normal-driven light wrap that follows the shape of the foreground, with a relight built on the same normals.

sid_lens_flare.py

Lens Flare — an image-driven, physically traced lens flare with lens dirt, custom shape inputs and look presets. Needs sid_lens_optics.py and the sid_flare_*.py files next to it.

Installation

  1. Copy the folder's contents into your Nuke user directory (the one already on NUKE_PATH, usually ~/.nuke), or any folder you add to NUKE_PATH.

  2. Already have a menu.py there? Merge in the registration lines from this one rather than overwriting your existing file.

  3. Restart Nuke. Nodes > Sid lists all eight tools.

No dependencies beyond Nuke's own Python.

Match tools

Each node takes Source (input 0), Target (input 1), and an optional Mask (input 2).

Neutralize

Matches Source's tonal bands to Target's band mean/stddev.

Match Black

Two-point affine solve pinned at white, matching Source's dark point to Target's.

Match White

Two-point affine solve pinned at black, matching Source's bright point to Target's.

Match Colour

Per-channel quantile/histogram match of Source to Target.

Preserve Saturation

Neutralize and Match Colour both have a Preserve Saturation toggle (off by default). Off, each channel is matched independently, same as before. On, brightness and saturation-strength are solved as two separate quantities — stays correct even when Target has had its Saturation or Gamma pushed around after the original grade.

Common match controls

Shared across all four match nodes.

  • Mode (Live/Locked) — Live re-samples automatically whenever inputs or key knobs change; Locked only updates when you click Set Reference.
  • Analyze — re-runs the match now.
  • Reference Frame + Set Reference — pick a specific frame of Target to lock onto.
  • Reset — clears the current match back to neutral.
  • Mask Applies To (Target/Source/Both) — when a Mask is connected, restricts which side's sampling is weighted by it.
  • View Mask — swaps the Output to show the raw Mask input, for checking coverage.
  • Clamp — Min/Max per channel, plus an All multiplier, limits the corrected output range.
  • Range — shows the lowest/highest sampled values on the node.

Edge tools

All three take a Mask input and a Mix slider for standard masked/partial application.

Edge Extend Blur

Cleans the RGB edge of a keyed or rotoed element so it blends into a new background without a dark or bright rim. The alpha is never changed. Inputs: Source, Sample, Mask and Omit.

  • Method — Clean Core Extend (replaces the contaminated edge with clean colour from further inside), Eroded Inner Ring Sample, or Dark / Bright Fringe Kill Only.
  • Clean Bias, Clear Dark / Clear White, All-Edge Strength — how strongly clean pixels win over contaminated ones, and how much of a dark or bright edge is replaced.
  • Edge Blend — feathers where the cleaned zone meets the original so no hard line shows.
  • Recover Grain + Grain Softness — brings the original texture back into the cleaned edge, with no blur.
  • Use Sample — a checkbox. Draw an area on the Sample input and the sampled colour is mixed over Clean Core only inside that area (a KeyMix), with Area Feather, Fill Softness, Gain and Gamma.
  • Omit — connect an alpha and the edge clean is skipped there.
  • Show Edge Matte — a checkbox that shows the edge band being treated. Edge Blur — a final colour-only blur in 0.1 steps.

Alpha Edge

Alpha-only processor — grow/shrink in sub-pixel 0.1 px steps, edge smoothing, contrast, and blur.

Light Wrap

Wraps the background light around a foreground so it follows the object's contours. Inputs: FG, BG, Mask and an optional Normals input. Instead of blurring the background in place, it builds normals for the whole foreground and picks the wrap colour up from the background along them.

  • Normals — from the alpha (a soft dome) and from the foreground's own luminance (bright = raised), so they follow surface detail across the whole object. Normal Source, Normal Blur, Normal Smooth, Normal Height, Detail Strength, Detail Smoothing, Normal Strength and Flip. View Normals shows them as colour.
  • Coverage — Edge Only, Grow Inwards (Wrap Depth) or Whole Object. Controls that do nothing in the current mode are greyed out. Wrap Softness smooths where the wrap ends.
  • Relight — a checkbox. The same normals light the foreground with a light direction, elevation, colour, intensity, softness and ambient; the wrap is applied on top.
  • Output — FG Only, FG Over BG, LightWrap Only (solo on black), or raw normals (float RGB with the foreground alpha) for other relight setups. Use Normals Input swaps in a normal map of your own.
  • Blend modes: Add, Screen, SoftLight, BG Bleed. The normals come from the alpha and the image luminance, not true depth; a real normal map is more accurate.

Lens tools

Lens Flare

An image-driven, physically traced lens flare: every highlight in the plate flares. Ghosts come from tracing light through a real lens prescription. Each reflection between two glass surfaces gives a ghost with its own position, flip, size, coating colour and colour fringing, and the highlights are convolved with the actual aperture shape. Takes the plate as input.

  • Lens — 50mm f/2, 24mm f/2.8 and 85mm f/1.8, or paste a custom prescription. F-Stop, blades, roundness and an anamorphic Squeeze (up to 2x). Overscan keeps shapes from being cropped at the frame edge.
  • Ghosts, Starburst and Veiling Glare — each with its own on/off switch. The starburst spike count follows the aperture blades.
  • Elements — Streak (up to 8), Spike Ball, Shimmer, Sparkle, Glint, Bloom, Iris, Multi-Iris, Rings, Caustic, Ring / Halo, Lens Orbs and Overscreen Wash. Each has Enable, Intensity, Tint and an optional Offset, and can be driven by every highlight or by a single detected hotspot per light.
  • Lens Dirt — dirt that is lit by the flare: six procedural layers (Specks, Smudges, Floaters, Fibres, Scratches, Fingerprint) or your own texture, with placement and noise breakup.
  • Custom shape inputs — connect an image for the Caustic, Ring or Aperture shape. The inputs only exist while chosen.
  • Look presets — Clean Prime, Vintage Uncoated, Anamorphic Sci-Fi and Sun Flare, plus your own saved looks. A Master section controls overall intensity, saturation, tint and flicker.
