Sid Nuke Tools

Five compositing utilities for Nuke, split into two families: colour matching (Neutralize, Match Black, Match White, Match Colour) and edge work (Alpha Edge). Written as plain Python nodes — each one solves for its correction live off the Source/Target pixels you give it, rather than asking you to eyeball sliders.

Overview

Two independent files, one shared install step. Nothing here replaces Nuke's native Grade/Roto — these are solvers: give a node a Source and a Target (and optionally a Mask) and it works out the correction itself.

sid_match_tools.py

Neutralize, Match Black, Match White, Match Colour — four ways to pull a Source plate's tonal range onto a Target's.

sid_edge_extend.py

Alpha Edge — grow, shrink, smooth and blur a rough matte edge.

Installation

  1. Copy the folder's contents into your Nuke user directory (the one already on NUKE_PATH, usually ~/.nuke), or any folder you add to NUKE_PATH.

  2. Already have a menu.py there? Merge in the registration lines from this one rather than overwriting your existing file.

  3. Restart Nuke. Nodes > Sid lists all five tools.

No dependencies beyond Nuke's own Python.

Match tools

Each node takes Source (input 0), Target (input 1), and an optional Mask (input 2).

Neutralize

Matches Source's tonal bands to Target's band mean/stddev.

Match Black

Two-point affine solve pinned at white, matching Source's dark point to Target's.

Match White

Two-point affine solve pinned at black, matching Source's bright point to Target's.

Match Colour

Per-channel quantile/histogram match of Source to Target.

Preserve Saturation

Neutralize and Match Colour both have a Preserve Saturation toggle (off by default). Off, each channel is matched independently, same as before. On, brightness and saturation-strength are solved as two separate quantities — stays correct even when Target has had its Saturation or Gamma pushed around after the original grade.

Common match controls

Shared across all four match nodes.

  • Mode (Live/Locked) — Live re-samples automatically whenever inputs or key knobs change; Locked only updates when you click Set Reference.
  • Analyze — re-runs the match now.
  • Reference Frame + Set Reference — pick a specific frame of Target to lock onto.
  • Reset — clears the current match back to neutral.
  • Mask Applies To (Target/Source/Both) — when a Mask is connected, restricts which side's sampling is weighted by it.
  • View Mask — swaps the Output to show the raw Mask input, for checking coverage.
  • Clamp — Min/Max per channel, plus an All multiplier, limits the corrected output range.
  • Range — shows the lowest/highest sampled values on the node.

Edge tools

Alpha Edge takes a Mask input and a Mix slider for standard masked/partial application.

Alpha Edge

Alpha-only processor — grow/shrink, edge smoothing, contrast, and blur.
